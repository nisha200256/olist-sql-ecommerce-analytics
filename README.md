📊 Olist E-Commerce Analytics Project
📌 Overview

This project analyzes a real-world e-commerce dataset to uncover insights into customer behavior, revenue trends, and product performance using SQL and Python.

🎯 Objectives
Analyze revenue and order trends
Understand customer behavior
Perform segmentation and retention analysis

🛠️ Tools Used
SQL (SQLite)
Python (Pandas, Matplotlib)
google colab
📂 Dataset
Orders
Order Items
Payments
Customers

💰 Revenue Analysis
Calculated total revenue and average order value
Identified monthly growth trends
📈 Monthly Revenue Trend

👥 Customer Segmentation
Segmented customers into Low, Medium, High value groups
🔁 Cohort Analysis
Analyzed customer retention over time

💡 Key Insights
Revenue is concentrated among a small group of high-value customers
Customer retention drops after first purchase
Certain regions contribute significantly to revenue
📌 Business Recommendations
Focus on retaining high-value customers
Improve post-purchase engagement
Target high-performing regions
