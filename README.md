# 🛒 Olist E-Commerce Analytics | SQL Data Analysis Project

## 📌 Project Overview
This project analyzes real-world e-commerce data using SQL to uncover business insights related to sales performance, customer behavior, and operational efficiency. The analysis is based on the Brazilian E-Commerce dataset provided by :contentReference[oaicite:0]{index=0}.

---

## 🎯 Business Problem
E-commerce companies need to understand customer behavior, revenue trends, and operational performance to optimize business outcomes. This project aims to:
- Analyze sales and revenue performance
- Identify high-value customers and top-performing products
- Evaluate order trends and seasonality
- Assess delivery performance and customer satisfaction

---

## 📊 Dataset Overview
The dataset contains ~100,000 orders with multiple related tables including customers, orders, payments, products, and reviews :contentReference[oaicite:1]{index=1}.

Key data domains:
- Orders & Transactions
- Customers & Locations
- Payments & Revenue
- Products & Categories
- Reviews & Delivery Performance

---

## 📈 Key Features
- 🧾 Multi-table SQL analysis using joins and aggregations
- 💰 Revenue and order trend analysis
- 🧍 Customer segmentation and behavior insights
- 🚚 Delivery time and logistics performance analysis
- ⭐ Review score and satisfaction analysis

---

## 🧠 Key Insights
- Identified peak sales periods and seasonal demand trends
- High-value customers contribute disproportionately to total revenue
- Delivery delays negatively impact customer review scores
- Certain product categories drive majority of sales volume

---

## 🛠 Tools & Technologies
- SQL (Joins, Aggregations, Window Functions)
- Database: MySQL / PostgreSQL
- Data Cleaning & Transformation
- Analytical Query Design

---

## 📊 Methodology

### 1. Data Preparation
- Imported and structured relational datasets
- Handled missing values and inconsistencies

### 2. Data Modeling
- Established relationships across multiple tables
- Used primary and foreign keys for accurate joins

### 3. Analysis
- Wrote SQL queries to calculate key business metrics:
  - Total revenue
  - Order volume
  - Average order value
  - Delivery time
- Performed time-series analysis for trend identification

### 4. Insight Generation
- Translated query results into business insights
- Identified opportunities for operational and revenue improvement
